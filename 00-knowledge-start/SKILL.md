# 지식 지도 입구

먼저 [knowledge-reading-rules](../rules/knowledge-reading-rules/SKILL.md)를 읽는다.

1. 업무·쟁점을 [issues](../issues/README.md)에서 찾는다. 쟁점이 없으면 미수록이라고 밝힌다.
2. 쟁점의 법령 조문·실무기준·업무 스킬 연결로 kapa_skills에 간다.
3. 연결된 [판례](../cases/README.md)·[해석](../interpretations/README.md)의 원문과 판본·후속 관계·[검토 기록](../reviews/README.md)을 확인한다.
4. coverage는 조사한 경로를 뜻할 뿐 모든 선례가 없다는 증명이 아니다.

갱신을 명시적으로 지시받은 경우만 [knowledge-update-maintenance](../rules/knowledge-update-maintenance/SKILL.md)로 넘어간다.
